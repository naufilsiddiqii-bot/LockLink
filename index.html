How Zero-Knowledge LockLink Works
1 Client-Side AES-256

Your URL is encrypted locally using PBKDF2 key derivation with 100,000 salt iterations and AES-256-GCM. No plain password or URL ever leaves your device.

2 Hash Fragment Storage

The encrypted payload (Ciphertext, IV, Salt) is stored strictly in the URL hash fragment (#data=...). Web browsers never send hash fragments to servers.

3 In-Browser Decryption

When the target user opens the link and enters the correct password, the browser derives the key and decrypts the destination URL right inside memory.
